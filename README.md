# Tobylğy · Қонақ бөлме — демо бет

Жиһаз дүкеніне арналған интерактивті бет үлгісі: бөлме панорамасы, суреттегі бағалар, тауар парақтары, қазақша/орысша.
Жарияланған нұсқасы: https://ulagat02.github.io/tobylgy/

Әр дүкенге өз брендімен, телефонымен және мекенжайымен көрсетілетін нұсқалар (бір бет, деректері ғана бөлек):
`zetta.html`, `zeta.html`, `symbat.html`. Негізгі бет `?store=zetta` параметрімен де сол дүкенді көрсетеді.

Бұл репозиторийде тек жарияланатын файлдар. Көзі мен құрылыс құжаты — жеке жобада (`furniture/room-hero.html`, `room-hero-LOGIC.md`, `make_stores.py`, `stores.json`).
